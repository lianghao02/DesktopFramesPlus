# 📦 v2.11.0：2D Q 版介面與收納面板

DesktopFramesPlus 維持「Data 分類面板＋獨立便箋」，並新增實際搬入資料夾的「收納面板」。此次 Windows x64 免安裝成品內含 .NET 8 Desktop Runtime，使用者不需另外安裝 .NET。v2.10.0 的收納面板功能未曾公開發布，本版一併包含。

## 重點更新

- **2D Q 版介面**：木框羊皮紙、布面標題、皮革按鈕與道具格；木框角飾與裝飾牌不再被拉伸變形，羊皮紙底紋依原比例平鋪。
- **收納面板**：直接拖入是搬移，按住 Ctrl 複製，按住 Alt 建立捷徑；拆除面板時內容移回桌面，不覆蓋同名檔案。用詞統一為「收納面板」與「捷徑面板」。
- **選單整理**：♥ 選單與面板右鍵選單把少用功能收進「更多」；設定視窗與「自訂外觀」視窗把少用選項收進預設收合的「進階（少用）」。
- **可讀性**：鎖定面板的鎖頭圖示在綠色標題列上改為奶油色底；♥ 加大並擴大可點擊範圍；「設定檔」統一稱為「工作區」。
- **修正**：圖示縮小殘影、尺寸吸附、隨 Windows 啟動寫入驗證。

## 使用與更新

下載 DesktopFramesPlus-v2.11.0-zh-TW.zip，解壓縮完整資料夾，再執行 Desktop Frames.exe。不要只取 EXE。更新前先結束舊程式並備份設定，保留自己的 Profiles，不要覆蓋或刪除個人資料。

## 驗證與限制

- Visual Studio MSBuild 自包含發布通過；成品 DLL 版本 2.11.0.0。
- 隔離驗收與代表性測試 152 項全過（對 PortablePublish 成品執行）、專用收納面板合成測試 10 項全過、繁中資源 100% 覆蓋。
- 驗收程式實際渲染設定視窗與面板畫面，確認木框、紙張底紋與「進階（少用）」區正常。
- ZIP 480 個檔案，不含 Profiles、PDB、記錄檔或驗收標記。
- 選單「更多」子選單與「自訂外觀」視窗沒有自動化畫面檢查；使用者已於發布前實際使用一輪。
- 不同電腦、無全域 .NET 的乾淨環境、Windows 10、ARM64、多螢幕／DPI 尚未實測；32 位元 Windows 不適用。企業防毒相容性不作保證。
- 沒有啟用 CI。

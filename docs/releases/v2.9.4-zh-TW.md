# 📦 v2.9.4：可攜發布與拖曳修正

DesktopFramesPlus 維持「Data 分類面板＋獨立便箋」，此次 Windows x64 免安裝成品內含 .NET 8 Desktop Runtime，使用者不需另外安裝 .NET。

## 重點更新

- 修正主區與分頁跨面板拖回後的圖示殘影，不需再縮放視窗才清空。
- 舊 Portal 路徑暫時離線時保留面板配置，恢復資料夾後下次啟動重新顯示；離線提示改為非阻塞視窗。
- Portal 採退場方式：保留瀏覽與開啟，停止拖入收納、剪下、實體改名及刪除。Data 面板不搬動來源檔案。
- 圖示移除清理沒有其他面板／分頁引用的捷徑副本；刪除面板只刪配置，不自動匯出桌面。
- 補強隔離驗收、成品 DLL 雜湊比對與內含 Runtime 檢查；設定檔結構不變。

## 使用與更新

下載 DesktopFramesPlus-v2.9.4-zh-TW.zip，解壓縮完整資料夾，再執行 Desktop Frames.exe。不要只取 EXE。更新前先結束舊程式並備份設定，保留自己的 Profiles，不要覆蓋或刪除個人資料。

## 最新使用者澄清：沿用現有面板，動物只有一隻
使用者明確選擇保留現有面板外觀與操作流程，直接使用桌面原圖示，不允許第二份入口。
桌面圖示拖入現有面板後，同一圖示移入並取得歸屬；跨面板仍是同一圖示；取消面板後解除歸屬，回到一般桌面，原檔位置與內容不變。
既有面板目前包含自行繪製圖示與建立／複製捷徑的流程，這條內容路徑不能用於原地模式。應保留現有面板外框與操作，將圖示管理接到原生桌面核心，不繼續擴充額外的柵欄介面。
尚未完成：既有面板接入方式、既有非桌面捷徑資料的保全邊界、內容穿透與面板取消的整合。不能把目前額外柵欄驗收版宣稱為符合此澄清後需求。

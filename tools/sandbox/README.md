# 🌾 農場柵欄最小操作原型 (Farm Fence Sandbox)

> **定位**：驗證「農場柵欄（手動拖入、原生圖示留存、原檔不變、不重複、拆除還原）」之獨立最小操作原型。  
> **隔離邊界**：本原型完全隔離於 `tools/sandbox/`，**正式主程式（`Code/Desktop Frames`）絲毫未動**。

---

## 一、核心架構與設計原理

本原型採用第一優先方案：**原生桌面圖示 ＋ 穿透外框（In-Place Fence）**。

1. **原檔與捷徑完全不動**：
   - 不複製檔案、不搬移實體檔案、不建立影子捷徑（.lnk）、不修改檔案屬性。
   - 透過已知資料夾 API（`SHGetKnownFolderPath`）解析真實桌面目錄，支援個人桌面與 OneDrive 重新導向（如 `C:\Users\chia-hao\Desktop`）。
2. **零注入與安全防禦相容**：
   - 實測發現：跨進程向 `explorer.exe` 調用 `WriteProcessMemory` 會被 Windows Defender / Exploit Protection 判定為注入攻擊並終止進程。
   - 本原型全面採用**純 Win32 唯讀讀取（`LVM_GETITEMPOSITION`）** 與 **標準 `LVM_SETITEMPOSITION`（`lParam` 封裝座標，免遠端記憶體寫入）**，達到 100% 零進程注入、零防毒攔截。
3. **穿透外框（`WM_NCHITTEST`）**：
   - 外框內部工作區返回 `HTTRANSPARENT`，所有滑鼠點擊、雙擊、右鍵快顯選單 **100% 穿透至底層桌面 `SysListView32`**，完全保有 Windows 原生桌面體驗。
   - 標題列返回 `HTCAPTION`（可平滑拖曳整體柵欄），四周邊框返回 `HTLEFT/HTRIGHT/HTTOP/HTBOTTOM`（可自由縮放調整大小）。
   - 設定 `WS_EX_NOACTIVATE`，點擊或操作外框時不搶走其他前台視窗焦點。
4. **物理空間邊界歸屬**：
   - 不依賴容易被其他視窗遮擋干擾的 `WindowFromPoint`，而是以原生圖示的實際螢幕邊界矩形與中心點，即時比對各柵欄的邊界矩形（`Rect.Contains`）。
   - 當使用者按住桌面圖示手動拖進柵欄，放開後圖示中心落在柵欄內，即判定歸屬該柵欄；拖出柵欄外則解除分組。
   - 當使用者拖動柵欄標題列時，連動內部被圈養的原生圖示同步位移。
   - 取消／關閉柵欄時，內部圖示自然停留在桌面原地，安全解除分組，絕不刪除檔案。
   - 每次分組變更或移動即時固化至 `fence_state.json`，關閉再重開可準確恢復狀態。

  - 拖至 Word 或瀏覽器等一般視窗時，是否會誤觸其他程式的檔案開啟。

## 三、如何啟動與手動實測

在終端機或檔案總管中：

1. **底層通信與圖示座標檢驗（CLI 模式）**：
   ```powershell
   .\tools\sandbox\bin\Debug\net8.0-windows7.0\FarmFenceSandbox.exe --test
   ```
2. **啟動雙柵欄與控制台（GUI 實測模式）**：
   ```powershell
   Start-Process .\tools\sandbox\bin\Debug\net8.0-windows7.0\FarmFenceSandbox.exe
   ```
   - 螢幕上會出現兩個柵欄：
     - **藍色外框**：柵欄 A (工作農場)
     - **綠色外框**：柵欄 B (暫存農場)
   - 可用滑鼠調整柵欄大小、拖曳標題列位置。
   - 將桌面上的檔案直接拖入柵欄中，觀察標題列項目數量與控制台日誌更新。
   - 點擊右上角 ✕ 取消柵欄，確認圖示安全留在桌面。
